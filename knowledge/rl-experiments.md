An experiment tests one habit on you. Nights come in pairs and a coin flip decides which night of each pair is
the habit night, so slow changes such as a busy week affect both nights equally. You confirm each morning
whether you kept the habit. The result uses a randomization test and a 95% interval, and is reported as helped,
worse, no meaningful effect or inconclusive. Two weeks can only detect fairly large effects, so inconclusive is
a common and honest answer. One person's result says nothing about other people.
